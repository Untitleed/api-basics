1. Czym jest JSON? 
tekstowy format zapisywania i przesyłania uporzadkowanych danych (to nie język programowania)

2. Jaka jest różnica między {} i []?
{} to Object - opisuje coś za pomocą nazwanych właściwości
[] to Array - przechowuje liste elementów w określonej kolejności

3. Dlaczego "123" i 123 mają różne typy danych?
"123" to string a 123 to number

4. Co oznacza null?
brak wartości =/= 0 

5. Jak odczytać drugi element tablicy skills z pliku JSON?
skills[1]
(Kropka . służy w wielu językach programowania do przechodzenia do nazwanej właściwości obiektu, np. contact.email. Nie wstawiamy kropki bezpośrednio przed nawiasem.)
